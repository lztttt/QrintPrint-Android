## QringPrint v1.5.0 更新

### 新增功能
- **错题本 · 文档增强算法升级**：高分辨率灰度光照补偿 → 缩放后二值化，小字不糊；Sauvola / Wolf / Bradley 三种二值化平铺选择可切换；增强强度可调（窗口 15~35、k 0.10~0.40，实时预览）
- **文字打印 · 横排优化**：按「打印宽度」自动折行（每行字符数与打印对应、不漏）；打印宽度可调（滑块+手动输入 100~1200 点、0=自适应、超纸宽自动分段拼接）；预览等比显示不变形
- **条码打印**：二维码纠错等级 L/M/Q/H；上/下方文字标注支持 {content} / {time_now} / {(1:100)} 变量；一键插入变量；批量打印

### Bug 修复
- 图片打印错位（断连重连残留状态 → 光栅错位）
- 横排打印内容超纸宽截断

### 其他
- 软件更新、APK 下载新增国内服务器源；新增词库国内服务器源
