## QringPrint v1.4.0 更新

### 新增功能

- **PDF 打印** — 选择 PDF 文件直接打印（图片型 PDF 按页面渲染）
  - 页码选择：支持打印全部页或仅当前页
  - 文档增强：默认使用 Sauvola 自适应二值化，自动补偿光照/阴影，文字表格更清晰（可切换普通阈值抖动，适合照片型页面）
  - 横向页面自动推荐旋转 90° 打印，长边沿出纸方向、分辨率最佳

- **批量打印** — 多选文字文件（txt / Markdown）与图片，一键批量连续打印
  - 文字排版（字号/行距/字体）与图片参数（抖动/阈值/浓度）全局预设，一次设置应用到所有项
  - 逐项打印进度显示，单项失败自动跳过并汇总原因
  - 文件清单可保存至历史记录，一键重打

- **横版照片智能推荐** — 图片打印检测到横版照片（宽>高）时弹出推荐，一键旋转 90° 打印：直接打印只是矮横条、细节大量丢失，旋转后长边沿出纸方向、打印分辨率最佳

- **课程表横版打印** — 整表旋转 90° 打印（长边沿出纸方向），横持查看仍是正常课程表（上面星期、左侧节次时间）

- **打印今日课程** — 自动按当天星期筛选课程，竖版清单打印当天节次（节次+时间 / 课程名+地点），跨节次课程自动合并显示

### 优化改进

- **单词本打印** — 预览防抖与超长截断、打印分块流式发送（防止超时）、行高与文字基线统一、历史重打完整还原、下载状态按书隔离、进度编辑失焦自动保存
- **Markdown 打印** — 修复加粗文字跨行丢失、行高计算统一、预览防抖与高度上限、超长内容分块流式打印、历史重打还原
- **图片打印** — 重写共享图像变换链（旋转→缩放→抖动顺序优化，输出恒定 384 点宽）
- **口算题打印** — 加法结果不超过所选范围、滑杆拖动防抖、大题量（200 题）分块打印防止超时、相邻重复题目洗牌打散
- **课程表** — 课程卡片占满完整单元格、时间显示加深加大
- **自定义打印** — 历史重打完整还原（文字内容/排版、图片、条码、旋转翻转反色、横竖排）、图片自动转存内部存储防止权限过期
- **口算题独立历史类型** — 不再混入"文字打印"，历史记录按"口算题"分类并可还原设置

### Bug 修复

- 修复课程表预览时课程卡片只占单元格 2/3 的问题
- 修复口算题"10 以内"加法结果可能超过 10 的问题
- 修复自定义打印历史重打内容丢失（文字、图片、条码、横竖排、变换全部丢失）
- 修复自定义打印图片 URI 权限过期导致重打失败
- 修复口算题历史记录误跳转"文字打印"页
- 修复横版照片推荐方向错误（原逻辑在已旋转时才提示、且推荐回 0°，实际应推荐旋转 90°）
